## changes
- `engine/src/sampling.rs`: `SamplingParams` (validated: finite temperature, top_p in (0, 1]; T <= 1e-5 is greedy),
  `argmax` (lowest index on ties, NaN ignored) and `Sampler` (seeded `StdRng`, candidate scratch preallocated to vocab
  so `sample` never heap-allocates). Softmax subtracts the max; top-p finds the nucleus by growing partial selection
  (`select_nth_unstable_by` on 64, 512, 4096, ... candidates, sorting only the newly selected block) instead of sorting
  128k entries. Ordering is weight desc then index asc, so results do not depend on the unstable algorithms.
- 12 CPU unit tests in the same file: greedy/ties, Llama-sized greedy, tiny T, same-seed determinism, tiny top_p,
  empirical distributions (full / temperature / top-p) with a 6-sigma binomial bound over 200k seeded draws, nucleus vs
  full-sort reference on 128256 logits, invalid params, invalid logits, no reallocation across steps.
- `lib.rs` not touched (`pub mod sampling` already declared). `error.rs` not touched: invalid params map to
  `KvasirError::Config`, bad logits to `KvasirError::Shape`.
- Bookkeeping: `.agent/backlog.yaml`, DESIGN.md §1/§7, CHANGELOG.md.
