## changes
- engine/kernels/attention.cu: rewritten. `attention_decode_{hd}_{g}`: flash-decoding, block per (KV head, context
  split), 8 lanes per 128-byte K/V row with 16-byte streaming loads, all g query heads share each load, exp2-domain
  online softmax, register prefetch of the next round, last-block-reduces split merge with a self-resetting counter.
  `attention_prefill_{hd}_{g}`: FA2-style causal prefill, 64 query rows per block, `mma.sync.m16n8k16` for QK^T and
  PV, cp.async double-buffered K/V tiles, `ldmatrix.trans` for V. Instantiated for head_dim 64/128 x group 1/2/4/8.
- engine/src/gpu/kernels.rs: `Gpu::attention` gains `scratch: &mut CudaViewMut<f32>`; new pub
  `kernels::attention_scratch_len(n_q, head_dim)`; dispatch decode (t == 1) / prefill; 48 KiB smem cap removed.
  Chunk heuristic `max(256, ceil(len/128))` chosen by sweeping chunk 32/64/128/256/512 and split caps 5/11/23/128.
- engine/tests/kernels.rs: attention tests take scratch; new tests: ctx 1, split boundaries (63/64/65/200/1000/2049/
  8191), 16k (beyond the old cap), 40k (> 128 splits), scratch reuse across calls (counter reset), hd 128 with groups
  1 and 8, prefill T=128/77 at Llama dims, long prefix (pos0=1000), prefill groups 1/8 and hd 128. Tolerance unchanged
  (2e-3 rel + 1e-3 abs); max error 6.6e-4.
- engine/benches/kernels.rs: outside the task's `files`, needed because the wrapper signature changed (allocates the
  scratch buffer before timing and passes it in). No other bench change.
- bench/kernels-baseline.json regenerated (only attention entries moved; all others within 1.6% of the old baseline).
- DESIGN.md §3 (algorithm, signature, scratch contract, alignment), §4 numerics, §7 rows, §8 numbers;
  CHANGELOG.md; .agent/backlog.yaml (A-01 added after H-01, done).
