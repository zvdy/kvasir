# Code of Conduct

kvasir follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

Report violations privately to the maintainers listed in [MAINTAINERS.md](MAINTAINERS.md) through a
[GitHub security advisory](https://github.com/zvdy/kvasir/security/advisories/new) marked "Code of Conduct", or to
the CNCF at conduct@cncf.io.
